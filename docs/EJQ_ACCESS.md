# 测量访问边界

普通协作者可读评分/校验代码，不读题干、答案键、逐题响应和单人量表结果。EJQ 原32题四卷及其 SHA-256 在仓库外由测量负责人保管。加载环境变量 SV2_EJQ_BANK，不设置时请求应明确失败；禁止生成临时替代题并称作原测量。

行为-only scripted 不需要题库，因此团队版资产清单去除私有题库条目；其他完整源文件保留。正式测量须先校验题库与 EXTERNAL_ARTIFACTS 中 private/EJQ_bank 的原 hash，另在 run manifest 记录 bank hash 和受控审批，不写题干。测试通过不能解除测量批准。

本次改动只影响装载位置与行为测试依赖，未改变题库内容或两层每层1分的评分。原有 test_phase18.py 含受限测量检查，只供持有题库的维护者后续授权运行；本轮普通团队验收不运行此测试。
