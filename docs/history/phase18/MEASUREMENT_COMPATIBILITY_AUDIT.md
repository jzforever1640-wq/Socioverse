版本：`1.8B-MAT-v0.3-CANDIDATE`；日期：2026-10-28（Asia/Shanghai）。

## 已实施与实际使用范围

当前原生研究入口仍使用原Phase1.8 v1两选项两层EJQ侧车与原风险问题；没有把v2候选题库或2031首职风险措辞静默替换进来。v2四选项/两层候选接口另作兼容测试，双方题库和评分键均保持原字节，分数不混算。Primary仍CS t5配对差。

旧与新两套题库的材料联动沿用v0.2逐项64题审计：旧G05/G08的8题、新A05/A08/B06/B07/C05/C08/D01/D07的8题为高近迁移候选。P101直接提供任务≠岗位、不同对象/任务/工具及中国毕业生外推边界，后测正确可以包含复述和近迁移。未发现P1给出题号、选项字母或题中特有数值答案，不等于没有语义答案提示。当前EJQ首先测AI Coding领域证据判断任务表现，不是已验证的一般跨领域稳定批判性思维。

P102/103补充四专业应用/工作方向，会影响专业认识和意愿解释；CS偏好升降不作为EJQ成功标准。风险仍是主观困难，不是客观失业概率。未把无法给分改填50，也未把四专业分数改为总和100。v2候选风险措辞若将来启用需独立版本确认；本轮没有替换。

## 门禁与分母

| 路径 | 本轮落实/验证 |
|---|---|
| 意愿 | 0–100独立、拒绝bool/NaN/超界；只有整体VALID/PARTIAL且该项非缺失/无missing_reason才入比较 |
| 风险 | 同一metric_value用于水平均值与变化量；整体VALID/PARTIAL＋风险状态VALID＋非缺失原因空＋有限0–100数值，否则排除 |
| EJQ v1 | 同一metric_value用于均值/变化；整体VALID/PARTIAL＋EJQ状态VALID＋有效两层总分，否则排除；不是把部分总分补零 |
| EJQ v2 | parse状态、逐题状态、分数范围与合计共同检查；总分不完整不入总均值/配对，已观测的完整维度和有效层可单列；无效外层状态不让残留16分流入表格 |
| 分母 | 原始固定roster提供24与SES每层8，不从返回行推；删去A001所有返回行仍保留原定24分母和缺失界限 |
| 缺失 | 保留PARTIAL/MISSING/NOT_COMPARABLE/NOT_SCHEDULED；不填0/50、不前值填补；缺共享基线不造组内变化，有有效t5完整对时仍可算端点差 |
| 模拟标签 | v1默认拒MOCK_ONLY，显式fixture输出SOFTWARE_TEST_ONLY；v2默认拒synthetic，未知或Mock数据类别拒收 |

变异注入将风险100/EJQ16保留、状态改为MISSING，均值和变化均为空；不因数值看似合理而接纳。部分记录仅相应已观测指标可用。v1/2均保留题目两层评分，不实质改题。

## 时点、相同题目与隔离

T0/T1/T2/T3严格对应t0/t1/t2/t5；t3/t4不伪造测量。t0/t1只保存COMMON一次。按同人BASE和阶段分卷，各分支同人同阶段题目hash一致，评分key共享；原64题未改。私人评测的答案、评分、rubric、状态和SES/arm元数据不进入行为prompt。

隐藏前缀后，旧依kind/P1_的检查会漏检；新门禁在后台根据材料映射、阶段和分支检查，再投影到K/R可见字段。t0/t1的P1、E1/E2的P1或支持来源均拒收。v1私有请求也必须给定后分支阶段的arm，不允许凭可见文本猜组。state.backend_scope只后台校验，未发送模型。

三个seed的私人v2兼容演练各读取240个实际保存状态，480次本地FakeClient函数调用，总计1440个接口夹具，无真实API；720份状态前后hash一致。请求未含答案键，后续社会状态/AgentMemory不写回评测结果。native52测试包含AgentMemory检查，测量65测试包含恶意客户端修改请求与原状态不变检查。oracle完美答卷仅验证评分和schema，不证明有效性、天花板或研究效应。

## SCA与真实院校接口

旧SCA登记仍对应旧S1_1/2/4，不能按位置自动套用新版。当前SCA_enabled=false，make_request直接报SCA_REGISTRY_REVIEW_REQUIRED_V03，测试确认不会到客户端；原登记/rubric保留归档，未造新正式主张。source_ids用R、parent_ids用K/M；未提供单独主张表时original_claim_ids为空，不假称完整原主张链已自动保留。

真实院校catalog和旧预测分数/位次不进入当前投影，constrained_choice_enabled=false。历史模块和证据不删除，仅保持停用。若未来主动加入SCA或v2候选，才需要该组件额外实质审批，不拿它阻塞当前不启用该组件的流程。
