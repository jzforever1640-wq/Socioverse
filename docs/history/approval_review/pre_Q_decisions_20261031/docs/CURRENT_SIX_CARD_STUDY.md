### PUB:P101 · AI编程工具能提高多少开发效率？

微软研究、METR实验｜研究者转述

三项企业随机实验涉及4867名软件开发者，随机给予部分人GitHub Copilot代码补全工具的使用资格。合并分析估计，实际使用工具者每周完成的代码合并请求数（研究的任务数量指标）提高约26%，但估计有较大不确定性；这不是所有获准使用者的简单平均，也不保证不同企业任务大小相同。

METR让16名熟悉自身开源项目的开发者完成246项真实任务；允许使用2025年初AI工具时，完成任务平均多花19%的时间。

这些研究的对象、工具、任务和指标不同；代码补全也不等于能自动执行多步任务的编程代理，不能由任务效率直接推断招聘人数。

### PUB:P102 · AI影响就业：哪些现象已经被观察到？

ILO、斯坦福、工信部｜研究者转述

国际劳工组织2025年估计，全球约四分之一的就业者处于某种程度暴露于生成式AI的职业中。这是依据职业任务评估的潜在影响，不是已消失岗位的比例。

斯坦福2026年8月修订研究使用截至2026年6月的美国ADP工资记录：较高AI暴露职业中22—25岁就业人数，比按低暴露同龄职业趋势推算的水平低约19%，差异主要来自招聘减少。研究是描述性观察，未证明AI是原因；控制教育因素后差异减弱，部分趋势在生成式AI普及前已出现，ADP样本的差异也比全国调查更大。研究未发现全经济范围普遍岗位替代的证据，这不等于排除局部影响或未来变化。

工信部公布2025年中国软件业务收入同比增长13.2%，收入增长不等于毕业生招聘增长。上述指标的对象和含义不同，不能相互抵消或据此预测中国某专业学生毕业后的就业。
